# Card

Service, build and blog cards: a square-cornered photo (4:3, vignette, focal point via `object-position`), a Big Shoulders title, an optional "from £" price in the red text gradient, and one plain line.

- The whole card is the link. Hover turns the title `accent`.
- Grid: `.hu-cards` auto-fills 260 px columns; use four columns on desktop when there are exactly four items so none sits alone on a row.
- Service images show the finished product, crisp and close (Hypa doesn't have to be in them). The main photo of a service stays the same on its own page and its hub card; "Related" rows rotate other real examples, and no image repeats on one page.
- Blog card: 3:2 thumbnail, category in mono, title, "Read the post" link.
- Shop card without a photo yet: dashed square placeholder "Photo coming soon".
- You provide: image + alt + focal point, title, line, price (optional), link.
