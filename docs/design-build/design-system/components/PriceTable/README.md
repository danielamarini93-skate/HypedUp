# PriceTable

Starting prices as a three-column table: what, from £, and a plain note. Used on Motorbikes (bike wraps by type) and Business (per vehicle), and wherever a service has tiers.

- Prices only from the master price list, always "from £", written with £. Missing price: "on enquiry".
- First column Big Shoulders uppercase; the rest Barlow `ink-body`. Mono table heads.
- Phone: the header row hides and each row stacks.
- Sits beside a short heading + one line ("Every bike is quoted on photos first.") in a split layout.
- You provide: rows (name, price, note).
