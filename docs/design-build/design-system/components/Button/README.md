# Button

Pill buttons in the logo's red gradient, Barlow 700 sentence case: the website's and social's call to action.

- `.hu-pill`: primary. One per screen. The main action is **Contact us**; nudges like "Send the spec" or "What are we building?" also work.
- `.hu-pill--ghost`: secondary, outlined in `ink`.
- `.hu-link`: text link with a `red-solid` Lucide arrow.
- `.hu-fab`: floating WhatsApp button on phones, red gradient with the WhatsApp icon (never WhatsApp green), fixed bottom-right.
- 48 px tall minimum (touch target). You provide the element (`<a>` or `<button>`) and the label.
