# FAQ

Questions as native `<details>` accordions, plus the two boxes that sit with them: **Explained** (hubs) and **Good to know** (services).

- Hubs: an Explained box (one big question answered in two lines, e.g. "Wrap, PPF or ceramic?") then 5 FAQs. Services: 4–5 FAQs. Never repeat the Explained question as an FAQ.
- Questions in the customer's voice ("Can I…?"), answers in "we", with one real detail. Facts only from the price list and memory; legal lines (tint 70 % / 75 %) as the law states them.
- The first item opens by default. The `+` turns into `×` when open. Summary rows are 56 px minimum (touch target).
- Native `<details>` works without JavaScript and with the keyboard.
- You provide: question/answer pairs, optional Explained title + text, optional Good to know line.
