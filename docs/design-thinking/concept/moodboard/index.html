Design thinking · Round 2 · Visual direction · v2

Style moodboard

Three ways to bring graffiti into Hyped Up, built from Dani's references. Each band: the references, a larger Hyped Up mock in that style (A and C switch between light and dark), then palette, type and a short read.

The rule all references follow: big, clean type carries the message; graffiti is one real layer on top, a tag or a spray word set in a proper font, or real graffiti in the photo. No fake spray.

Direction A

Street editorial

A car-culture magazine. Wide heavy type, mono captions, black-and-white halftone photos with one orange tag, stickers, crop marks and a barcode. Photo: the red Mini at a show, someone in a hoodie beside it: culture and people.

Direction B

Spray machine

Dark and loud, no fake spray. The graffiti is real: the workshop mural behind the red Mini, and one word set in a dripping spray-paint font. Clean condensed type (the menu & footer fonts: Big Shoulders + Barlow) and pill buttons do the rest.
