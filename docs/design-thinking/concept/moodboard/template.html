Design thinking · Round 2 · Visual direction

Style moodboard

Three ways to bring graffiti into Hyped Up, built from Dani's references. Each band shows the references it draws on, the palette and type, and a small mock of Hyped Up in that style.

What every reference does: big, bold, clean type carries the message; graffiti is one layer on top (a tag, a spray word, one brush stroke). Never the font you have to read.

Direction A

Street editorial

A streetwear magazine: grey paper, huge wide type, black-and-white photos with an orange graffiti tag scrawled over them, stickers, barcodes and small mono text. Busy in a designed way.

Direction B

Spray machine

Dark and loud. Clean condensed headlines in white, with one spray-paint word in orange that drips. Real workshop photos dimmed behind. A spray-blob for the main action. Closest to the current concept, but done properly.
